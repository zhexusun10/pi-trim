# Contributing

Use English for issues, pull requests, and primary documentation; Chinese translations are welcome.

Run `npm ci --ignore-scripts`, `npm run check`, `npm test`, and `npm run benchmark`. Keep the published extension free of network access and filesystem operations. New removal rules should match recognizable Pi boilerplate and include a regression test that preserves user instructions with similar text.

Report measurements with Pi version, tokenizer/model, fixture, tool configuration, and cache conditions. Do not describe estimated counts as billing data or claim better model quality from prompt-size changes alone.
